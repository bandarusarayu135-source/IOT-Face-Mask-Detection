# IoT Face Mask Detection and Body Temperature Monitoring

## Project Overview
This academic project explores an IoT-based system designed to identify face-mask usage and monitor body temperature for automated entry screening.

## Objectives
- Identify whether a mask is properly worn, incorrectly worn, or absent.
- Monitor body temperature using a temperature sensor.
- Explore automated entry control based on mask detection and temperature thresholds.

## Proposed Components
- Raspberry Pi
- Camera
- OpenCV and Python
- Temperature sensor
- LCD display
- Buzzer and motorized barrier
- IoT components

## System Workflow
The proposed system uses camera input for face-mask detection and temperature readings for screening. Based on the configured conditions, it is designed to support entry-control decisions.

## Project Contribution
Academic project study and documentation of the proposed system architecture and workflow.
